# Beach House / 54 Images

**A box of fifty-four cards, one for each Beach House song.<br>Draw a card and its song plays.**

An unofficial fan site for the 20th anniversary of Beach House's debut (October 3, 2006).

Every card holds one image for one song: a pool that turned into the sea, a night bus going through space, a house where the sun only reaches the toys. When you draw a card it develops like a photograph, the table takes on its colours, and the song starts playing. Turn the card over and there's a handwritten note on the back.

There are no rules. Browse the deck one card at a time, lay out a three-card reading, or spread all 54 across the table and arrange them however you like. Leave it playing and it deals the next card when each song ends.

> *They aren't illustrations. They're what I saw with my eyes closed.*
>
> <sub>from the letter on top of the deck</sub>

## What's in the box

- **54 cards** across nine albums, from *Beach House* (2006) to *Become* (2023)
- **Music on every card.** Full tracks if you're signed in to Spotify in that browser, 30-second previews if not
- **A note on the back** of every card, in handwriting
- **Three-card readings** you can share. The link *is* the reading
- **A table that changes with the card.** Its colours come from the image, and some cards bring their own light
- **Works on phones.** Swipe through the deck, tap to turn a card over
- **Remembers you.** Your progress and your Spread layout are saved in your browser

Click the lid. There's a folded letter on top of the deck; click it to read it, or go straight to **Draw the first card**.

### 2. Draw a card

This is the **Table**. One card at a time, and its song plays as it lands.

- **Draw at random**: click the deck on the left, or press <kbd>D</kbd>
- **Go through in order**: the arrows beside the card, or <kbd>←</kbd> <kbd>→</kbd> (swipe on a phone)
- **Read the back**: click the card, **Turn it over**, or <kbd>Space</kbd>

### 3. Ask for a reading

Open **Reading** (or press <kbd>R</kbd>) and three cards are dealt: *what you remember*, *what you're hearing* and *what you're becoming*. Their songs play in that order. Tap a card to jump to it, tap it again to pick it up.

**Share this reading** gives you a link like [`#/reading/0-30-51`](https://beachhouseappreciation.vercel.app/#/reading/0-30-51) (through your phone's share sheet, or copied to the clipboard), so a friend opens exactly the same three cards.

<img src="docs/screenshots/reading.jpg" alt="A three-card reading: Saltwater, Space Song and American Daughter" />

### 4. Spread them out

Open **Spread** (or press <kbd>S</kbd>) to see the whole deck on the table. Cards you haven't drawn yet lie face down, and the bar counts how many you've turned over.

- **Drag** cards anywhere. Your layout is kept for next time
- **Tap** a card to draw it
- **By album** sorts them into piles, **Gather** lines them up in rows, **Scatter** throws them across the table

<img src="docs/screenshots/spread.jpg" alt="The Spread, sorted by album, with 34 of 54 cards turned over" />

### 5. Let it play

The bar along the bottom controls the music.

- **Play the deck**: when a song ends, the next card is dealt for you (a reading plays its three songs and then stops)
- **Sound on / off**: draw in silence
- **Open in Spotify**: carry on in the app

## Under the hood

About 1,700 lines of plain HTML, CSS and JavaScript. No framework, no bundler, no build step, nothing to install to run it.

- **Each card colours the table.** `scripts/palettes.py` reads every image and derives a palette from it. The colours are registered CSS custom properties (`@property`), so the whole page fades from one card's colours to the next.
- **The light is a canvas.** `caustics.js` draws slow, moving light over the table, tinted by the card in hand, with its own moods for a few songs.
- **The URL is the state.** `#/card/30`, `#/reading/0-30-51` and `#/spread` are all real addresses, which is how readings are shared.
- **Music without a backend.** Songs play through Spotify's embed. Spotify doesn't say when a track ends, so the site watches the playback position to know when to deal the next card, and falls back to a plain embed if Spotify's player script is blocked.
- **The README draws itself.** Every image on this page, including the animation at the top, is captured from the running site by a pre-commit hook, so the README always matches the app.

## Run it yourself

Just want to use it? It's live at **[beachhouseappreciation.vercel.app](https://beachhouseappreciation.vercel.app/)**. To run your own copy, clone it and serve the folder; there's nothing to build.

```bash
git clone https://github.com/dpappo/beach_house_appreciation.git
cd beach_house_appreciation
python3 scripts/serve.py
```

Then open http://localhost:4321. To host it, upload the folder to any static host (GitHub Pages, Netlify, Vercel…).

## Make a deck for your own band

The deck is just data, so it works for any artist whose songs mean something to you.

1. **Write your cards** in `data/cards.source.json`: a title, album, year and an image prompt for each song (the array index is the card number).
2. **Make the images.** Put `OPENAI_API_KEY=...` in `.env`, then:
   ```bash
   node --env-file=.env scripts/generate.mjs
   python3 scripts/thumbs.py
   python3 scripts/palettes.py
   ```
   Or skip generation and drop your own art in as `images/00.webp`, `images/01.webp`, …
3. **Add the music and notes** in `data/cards.json`: each card's Spotify track ID and the `note` written on its back.
4. **Rewrite the letter** in `index.html` (`#letter`) and the About text.

The Beach House touches (velvet for *Depression Cherry*, the per-card lighting in `caustics.js`, the hidden card) are keyed to card numbers, so adjust or remove them for your deck.

<details>
<summary><b>How it's put together</b></summary>
<br>

| Path | What's there |
| --- | --- |
| `index.html`, `app.js`, `styles.css` | The whole site: views, routing (`#/card/12`, `#/reading/12-30-44`, `#/spread`), the card animations |
| `caustics.js` | The moving light on the table, drawn on a canvas |
| `data/cards.source.json` | Title, album, year and image prompt for every card |
| `data/cards.json` | What the site loads: adds Spotify track IDs, *Once Twice Melody* chapters and the `note` on each card's back |
| `data/palettes.json` | Per-card table colours, derived from each image by `scripts/palettes.py` (missing cards get `null` and keep the plain paper) |
| `data/generation-log.json` | Per-card generation record, including whether a safety note had to be appended |
| `images/NN.webp` | The cards. `images/back.webp` is the card back, `images/thumbs/` holds the Spread thumbnails |
| `docs/screenshots/` | The images in this README, captured by `scripts/screenshots.mjs` (the animation is encoded by `scripts/animate.py`) |

</details>

<details>
<summary><b>Regenerating images</b></summary>
<br>

```bash
node --env-file=.env scripts/generate.mjs --only 12,30 --force
python3 scripts/thumbs.py
python3 scripts/palettes.py
```

Without `--force`, cards that already have an image are skipped. `palettes.py` re-reads every card (a few seconds), so rerun it whenever images change. If the model's safety filter blocks a prompt twice, the script retries with one appended line ("All figures are fully and modestly clothed…") and records that in the log.

</details>

<details>
<summary><b>Keeping the README images current</b></summary>
<br>

The images in this README are generated, not hand-made. `npm install` once to get Playwright and turn on the repo's git hooks; after that, any commit that changes the site (`index.html`, `app.js`, `styles.css`, `caustics.js`, card data or images) recaptures them and adds them to that commit, so what you push always matches the app. It uses your installed Chrome if you have one, and Python 3 with Pillow to encode the animation.

```bash
npm install
```

To refresh them by hand, run `npm run screenshots` (about a minute). To skip the refresh for one commit, run `SKIP_SCREENSHOTS=1 git commit …`.

`docs/screenshots/social.jpg` is the repo's link preview. GitHub doesn't take it from the repo, so upload it under **Settings → General → Social preview** whenever it changes.

</details>
